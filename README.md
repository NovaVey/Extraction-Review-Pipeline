# Extraction-Review-Pipeline
[![CI](https://github.com/NovaVey/Extraction-Review-Pipeline/actions/workflows/ci.yml/badge.svg)](https://github.com/NovaVey/Extraction-Review-Pipeline/actions/workflows/ci.yml)

Document extraction with a confidence score you can act on: per-field evidence scoring instead of model self-report, a keyboard-fast review queue for anything uncertain, full correction audit trail, and a gold-set eval harness that reports auto-accept precision. TypeScript, Fastify, Postgres.

## Synthetic data

Every document under `/samples` is synthetic — generated by `scripts/make-synthetic-docs.ts` (`npm run gen:samples`). Vendor names, amounts, dates, and line items are all fabricated for testing; none of it is real personal or business data. `samples/manifest.json` records the ground-truth field values used to generate each document.
